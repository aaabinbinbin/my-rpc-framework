# 面试讲解脚手架

## 1. 最短 30 秒版本

`这是一个自研 RPC 框架项目，核心目标是让 consumer 像本地调用一样调用 provider 服务。项目实现了服务注册发现、代理调用、Netty 传输、序列化、负载均衡，以及 Spring / Spring Boot 集成，并补充了重试、熔断、限流等基础治理能力。`

## 2. 1 分钟版本

可以按下面顺序讲：

1. 项目目标：实现一个自己的 RPC 框架
2. 主链路：consumer 通过代理发请求，provider 执行业务并返回
3. 核心模块：rpc-core、rpc-spring、starter、example-api/provider/consumer
4. 关键能力：注册发现、Netty 通信、可插拔扩展、基础容错
5. 设计价值：分层清晰，便于扩展和接入真实业务

## 3. 2 分钟版本

在 1 分钟版本基础上，再补：
1. 为什么要拆 `example-api`
2. 为什么要把 Spring 集成和 core 分开
3. 为什么容错能力不能散落在业务代码里

## 4. 小白怎么避免讲崩

记住一个原则：

`先讲主链路，再讲专题，不要一上来就讲 Netty 和协议头。`
