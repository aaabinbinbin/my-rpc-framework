# 简历版项目描述小白模板

## 1. 这篇文档适合谁

适合：
1. 已经大致看懂项目
2. 想知道简历里怎么写
3. 还不会把技术实现压缩成几句话

## 2. 一版最稳妥的简历描述

可以写成：

`基于 Java 实现了一个自研 RPC 框架，支持服务注册与发现、动态代理调用、Netty 网络通信、可插拔序列化与负载均衡，并完成了 Spring / Spring Boot 集成以及基础容错能力设计。`

## 3. 如果想写得更具体一点

可以扩成：

1. 实现了 provider / consumer 基本通信链路
2. 支持通过代理将本地调用转为远程调用
3. 基于注册中心实现服务注册和发现
4. 基于 Netty 实现请求响应通信
5. 支持多种序列化和负载均衡策略
6. 提供重试、熔断、降级、限流等基础治理能力
7. 提供 Spring / Spring Boot 集成能力

## 4. 小白最容易犯的错误

不要写得太空：
1. 不要只写“做了 RPC 项目”
2. 不要只写“用到了 Netty、ZooKeeper”
3. 要写清楚你到底实现了什么链路和能力

## 5. 一句话提醒

简历不是源码目录，重点不是列类名，而是讲清楚你真正做成了什么。
